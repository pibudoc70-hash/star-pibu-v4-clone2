# 데스크톱 이벤트 미리보기 이미지 초점 관리

## 목적과 적용 범위

홈페이지 SPECIAL EVENT의 데스크톱 선택 미리보기는 3:2 고정 프레임에서 `object-fit: cover`를 사용합니다. 기본 초점은 `center center`이며, 아래 CSS 규칙은 인물이나 장비가 중앙 크롭에서 벗어나는 기존 이벤트에 한해 가로 초점을 보정합니다. 이 규칙은 이벤트의 제목이나 이미지 URL이 아니라 **데이터베이스 이벤트 ID**에 직접 의존합니다.

## 신규 이벤트와 DB ID 변경 시 동작

새 이벤트를 추가했지만 이 표와 CSS에 ID별 규칙을 추가하지 않은 경우, 오류는 발생하지 않습니다. 대신 기본 규칙인 `object-position: center center`가 적용되어 이미지는 중앙을 기준으로 크롭됩니다. 배너의 주 피사체가 중앙에 있지 않다면 인물·장비·문구가 어색하게 잘릴 수 있습니다.

DB 재시드나 데이터 이관으로 이벤트 ID가 바뀌면 기존 CSS 선택자는 새 ID와 더 이상 일치하지 않습니다. 이 경우에도 브라우저나 관리자 화면에서 오류를 내지 않고 중앙 크롭으로 조용히 되돌아가므로, 이벤트 목록·이미지는 정상처럼 보이지만 의도했던 개별 초점이 사라질 수 있습니다. 반대로 남은 이전 ID 규칙은 더 이상 사용되지 않는 CSS가 됩니다.

## 새 이벤트 또는 ID 변경 후 재설정 절차

새 이벤트를 발행하거나 기존 이벤트 ID가 변경된 경우에는 먼저 데스크톱 SPECIAL EVENT 미리보기에서 해당 카드 루트의 `data-event-id` 값을 확인합니다. 다음으로 `client/src/index.css`의 기존 ID별 초점 블록에 같은 선택자 형식으로 규칙을 추가하거나 변경된 ID로 교체합니다. `object-position`은 우선 `center center`에서 시작하고, 1280px 이상에서 실제 미리보기를 확인하면서 피사체가 자연스럽게 보이는 수평 위치로 조정합니다.

변경 후에는 새 ID가 기존 ID 규칙과 중복되지 않는지, 데스크톱 미리보기만 영향을 받는지, 그리고 모바일 이벤트 목록에는 의도하지 않은 크롭 변화가 없는지를 확인합니다. 이 CSS 매핑을 갱신하는 작업은 이벤트 제목·가격·상담 경로나 이벤트 데이터 자체를 수정하지 않아야 합니다.

## 장기 개선안

장기적으로는 초점 값을 CSS의 ID 선택자가 아닌 이벤트 데이터의 명시적 필드(예: `imageObjectPosition`)로 이관하는 방식을 검토할 수 있습니다. 그러면 ID 재시드에 덜 취약하고, 이벤트별 이미지 편집 화면에서 초점을 함께 관리할 수 있습니다. 다만 이 개선은 DB 스키마·이벤트 응답·관리자 편집 화면·데이터 마이그레이션·회귀 테스트를 함께 변경하므로 **별도 승인 필요**입니다. 이번 단계에서는 이러한 구조 변경을 수행하지 않습니다.

# 울쎄라피 프라임 모바일 카드 간격 점검

## 초기 390px 캡처 관찰

로컬 Chromium 390px 폭 전체 캡처를 세로 타일로 점검했다. 시맨틱 원리 섹션 시작부에서 카드 자체는 내용에 따라 높이가 형성되지만, 상세 소개 문단 종료 후 원리 섹션 카드 시작 전에는 사용자 체감상 큰 공백이 관찰됐다. 이는 개별 카드 내부의 고정 높이보다 상세 페이지의 다중 `mb-12`, 원리 섹션 루트 여백, 내부 `space-y-12` 누적을 함께 정리해야 함을 시사한다.

피부층 카드 시작부에서는 단일 일러스트와 첫 깊이 카드가 정상적으로 수직 흐름으로 배치됐고, 해당 이미지 자체가 카드와 나란히 놓여 남는 세로 공간을 만드는 구조는 아니었다. 이후 4단계·타임라인·기대 효과·주의사항까지는 수정 후 동일 방식으로 이어서 판독한다.

## 코드 점검 결과

현재 `UltherapyPrincipleSection`에는 고정 `height`, 과도한 `min-height`, 또는 모바일 `flex: 1` 규칙이 없다. 다만 루트의 `mb-12`, 내부 `space-y-12`, 각 상세 섹션의 `mb-12`가 모바일에서도 누적될 수 있으므로, 모바일 범위에서 카드·섹션 간격을 명시적으로 20–32px 수준으로 제한하고 카드 요소의 `height/min-height/flex`를 auto/initial로 보정한다.

## 수정 후 390px 재측정

원인은 `@media (max-width: 767px)` 안의 전역 `section:not(#contact)` 규칙이 모든 섹션에 상·하 80px 패딩을 강제한 것이었다. 이 규칙은 `!important` 및 components 레이어에 있었으므로, 같은 레이어에서 장비 상세 `#main-content` 범위만 재정의했다.

| 대상 | 수정 전 높이 | 수정 후 높이 | 수정 후 상·하 패딩 |
| --- | ---: | ---: | ---: |
| 시술 소개 | 407px | 247px | 0px / 0px |
| 울쎄라피 원리 전체 | 3,024px | 2,352px | 0px / 0px |
| 피부층·목표 깊이 | 756px | 596px | 0px / 0px |
| 4단계 시술 원리 | 943px | 783px | 0px / 0px |
| 회복 과정 타임라인 | 632px | 512px | 20px / 20px |
| 기대 효과 | 264px | 104px | 0px / 0px |
| 주의사항 | 304px | 144px | 0px / 0px |

수정 후 전체 390px 폭 캡처에서 피부층 카드, 4단계 카드, 타임라인, 안내문, 기대 효과, 주의사항, FAQ, 진료소 안내, 가이드 영상까지 순서대로 확인했다. 인접 상세 섹션은 32px, 원리 내부 블록은 24px 간격으로 이어지며, 사용자 요청에 나온 100px 이상 공백은 관찰되지 않았다. 데스크톱 CSS에는 변경을 추가하지 않았다.

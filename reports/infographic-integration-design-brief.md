## 시각 검증 기록

데스크톱 1280px 전체 페이지 캡처를 울쎄라피 프라임·써마지 FLX에 각각 1회 요청했으나, 두 경로 모두 캡처 서비스가 이미 알려진 방식으로 실패했습니다. 이는 화면 소스·TypeScript·전용 렌더링 계약 테스트와 별개의 도구 제약으로 기록합니다. 실제 브라우저에서 두 상세 페이지의 데이터 로드와 텍스트 콘텐츠는 앞선 장비 페이지 검증에서 정상 확인됐으며, 인포그래픽 영역은 전용 회귀 계약으로 보완합니다.

이후 두 페이지를 실제 브라우저로 재확인했습니다. 두 경우 모두 `시술 소개` 다음에 `시술 원리 인포그래픽` 섹션, 해당 장비의 설명형 대체 텍스트, 개인차 안내문이 순서대로 렌더링됐습니다. 원본 이미지 자체는 기본 지연 로딩이므로 현재 상단 뷰포트의 캡처에는 이미지 영역이 비어 보일 수 있으나, 페이지 추출 결과에서 두 `/manus-storage/` WebP URL과 콘텐츠가 확인됐습니다.

390px 전체 페이지 캡처도 두 경로에서 각각 시도했으나, 캡처 서비스가 두 요청 모두 실패했습니다. 이미지에는 고정 폭·높이를 부여하지 않고 `w-full h-auto`로 단일 열 컨테이너에 맞추며, intrinsic `width=1440`·`height=1800`을 지정해 모바일에서도 비율과 레이아웃 안정성을 유지하도록 구현했습니다.

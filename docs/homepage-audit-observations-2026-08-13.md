## 오시는 길 페이지

- 대상 URL: `https://star-pibu.com/directions`
- 주소·전화·진료시간·카카오맵·네이버지도 외부 링크는 렌더링되었으나, 데스크톱 지도 영역은 실제 지도 타일·임베드 대신 큰 회색 빈 영역으로 나타났다.
- 같은 페이지에서 본문은 `서면역 5·7번 출구 도보 3분`, Footer는 `도보 2분`으로 표기되어 있어 위치 안내 정보의 단일 원본 관리가 필요하다.
- 활성 `/directions` 라우트는 `client/src/pages/Directions.tsx`를 사용하지만, 파일 상단 주석은 이를 비활성·고아 페이지로 기술해 실제 코드와 문서가 불일치한다.
- 현재 iframe 원본 URL(`https://maps.google.com/maps?...&output=embed`)은 외부 응답 확인에서 HTTP 404를 반환했다. CSP에는 Google Maps 프레임 출처가 허용돼 있으므로, 우선 원인은 CSP가 아니라 iframe URL·공급자 동작의 신뢰성으로 판단한다.
- `/zh-tw/directions`에서도 같은 회색 빈 지도 영역이 재현됐다. 따라서 지도 문제는 한국어 단일 페이지가 아니라 공통 `Directions` 컴포넌트의 다국어 영향 문제다.
- 번체 중국어의 주소 복사(`複製地址`)·Google Maps 길찾기·Footer 주요 라벨은 현지화되어 렌더링되었다. 다만 동일 페이지 본문 교통 안내는 `도보 3분`, Footer는 `도보 2분`으로 언어와 무관하게 불일치한다.

## 1단계 구현 검증 메모

- 기존 iframe을 공통 `MapView`로 교체한 개발 화면에서도 지도 영역은 즉시 타일을 표시하지 않고 회색으로 남았다. 콘솔에는 별도 오류가 기록되지 않아, 지도 스크립트 로드 대기·렌더 초기화·제공자 응답을 분리해 추가 확인한다.
- 진단 결과 공통 Maps 프록시 스크립트와 `window.google.maps.Map` 생성자 자체는 로드·호출되지만, 생성 컨테이너에 실제 `gm-style` 지도 타일 DOM이 생성되지 않았다. 따라서 단순 iframe 교체만으로는 해결되지 않으며, 공통 지도 컴포넌트의 프록시 초기화·지도 설정을 추가로 점검해야 한다.
- 개발 네트워크 로그에서 Google Maps 런타임의 CSP 검사 요청(`https://maps.googleapis.com/maps/api/mapsjs/gen_204?csp_test=true`)이 네트워크 오류로 실패했다. 현 `connect-src`에는 `maps.googleapis.com`이 없으므로, 지도 SDK가 요구하는 최소 출처를 CSP에 추가한 뒤 타일 렌더링을 재검증한다.
- `maps.googleapis.com`과 `maps.gstatic.com`의 최소 CSP 허용 후에도 개발 Directions의 지도 타일은 표시되지 않았다. 지도 자체가 표시되는지 여부를 성공 기준으로 유지하며, 이 상태에서는 운영 배포·다음 단계 진행을 하지 않는다.
- 지도 컨테이너는 실제로 약 811×400px 치수를 가지지만 내부에 `gm-style` 타일 DOM이 생기지 않았다. 따라서 레이아웃 높이 문제가 아니라 지도 스크립트 런타임이 렌더러를 완성하지 못하는 문제로 분류한다.
- Google Maps 객체는 약 3초 후 정적 대체 지도 이미지를 생성했지만 `idle`·`tilesloaded` 이벤트가 발생하지 않아 확대·축소·드래그 가능한 인터랙티브 지도 초기화에는 실패했다. 개발 화면에서 정적 이미지의 일부는 확인됐으나 대형 지도 컨테이너 전체를 채우지 못해 해결 상태로 판정하지 않는다.
- 타일 미초기화 감지 후 8초에 한국어 Directions는 `스타피부과 위치 지도`와 `카카오맵으로 보기` 외부 링크를 지도 영역 안에 표시했다. 따라서 기존의 빈 회색 박스 문제는 명시적·키보드 접근 가능한 대체 UI로 해소됐지만, 페이지 내 확대·축소·드래그형 지도를 충족하지는 못했다.
- `/zh-tw/directions`도 같은 실패 조건에서 번체 안내와 `hl=zh-TW`가 포함된 Google Maps 길찾기 링크로 전환되는 것을 확인했다. 한국어·외국어의 기존 길찾기 정책은 대체 UI에서도 유지된다.

## 2단계 운영 검증 메모

- 운영 `/zh-tw/directions`의 Directions 본문은 `步行3分鐘`으로 갱신됐으나 Footer는 아직 `步行2分鐘`을 표시했다. 번체 Footer의 별도 override 또는 렌더링 경로를 추적해 같은 3분 기준으로 추가 수정한다.
- 백업 사이트의 지도 DOM은 Google Maps 런타임이 생성한 `StaticMapService.GetMapImage` 이미지를 표시하고 있으며, 이는 확대·축소 상호작용을 제공하는 활성 지도 화면이 아니라 정적 이미지 렌더링 형태다. 현재 요구사항은 인터랙티브 지도를 우선하므로, 정적 이미지로 되돌리는 방식은 채택하지 않는다.

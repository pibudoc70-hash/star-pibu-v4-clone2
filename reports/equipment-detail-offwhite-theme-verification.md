# 장비 상세 오프화이트 시범 테마 검증 기록

## 브라우저 렌더링 표본

2026-08-28 개발 미리보기에서 울쎄라피 프라임 상세 페이지를 실제로 확인했습니다.

| 항목 | 결과 |
|---|---|
| 초기 로더 | 로딩 완료 뒤 페이지 제목·이미지·기본 정보·FAQ summary·목록 버튼이 정상 렌더링되었습니다. |
| CTA | 카카오톡 상담·네이버 예약 링크가 모두 접근 가능한 링크로 렌더링되었습니다. |
| FAQ | 7개 질문이 `<summary>` 인터랙션으로 렌더링되어 키보드 초점 대상임을 확인했습니다. |
| 본문·인포그래픽 | 시술 소개와 인포그래픽이 정상 렌더링되었고, 기존 정보 흐름은 유지되었습니다. |

브라우저의 첫 화면은 이미지·기본 정보·CTA까지 보였고, FAQ·진료 안내 카드는 아래 스크롤 영역에 있습니다. CSS에서 해당 영역을 장비 상세 한정 `.equipment-detail__faq-item`, `.equipment-detail__info-card`로 지정했으며, source contract 테스트와 WCAG 대비 계산으로 시범 테마 규칙을 함께 검증했습니다.

## 실제 CTA 호버 검사

브라우저에서 카카오톡 상담 CTA에 포인터를 놓은 뒤, 계산된 스타일을 확인했습니다. `:hover`가 true이고 `translateY(-2px)` transform, 네이비 shadow, 금색 focus-ring 계열 외곽선이 적용됐습니다. 기본 CTA의 카카오 노랑과 텍스트 색은 브랜드 구성을 보존하고, 시각 피드백만 공통 class에서 보강했습니다.

| 검사 항목 | 계산 결과 |
|---|---|
| hover 상태 | `true` |
| transform | `matrix(1, 0, 0, 1, 0, -2)` |
| shadow | `0 10px 22px rgba(26,39,68,.18)` + `0 0 0 2px rgba(196,168,130,.24)` |
| transition | transform 160ms, shadow·색상 180ms |
| FAQ 카드 표면 | `rgb(247, 245, 240)` (`#F7F5F0`) |

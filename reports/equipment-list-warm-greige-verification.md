# 장비 목록 웜 그레이지 시범 테마 브라우저 확인

## 실제 렌더링 확인

2026-08-28 개발 미리보기의 `/equipment3`에서 데이터 로딩 완료 후 다음을 확인했습니다.

| 영역 | 확인 결과 |
|---|---|
| 페이지 바탕 | 헤더 아래 장비 소개·카테고리·검색·카드 영역이 순백색 대신 차분한 웜 그레이지 계열로 구분되어 보입니다. |
| 카테고리·검색 | 두 surface가 페이지 바탕과 카드 사이에 미세한 경계·그림자로 구획되며, 탭 텍스트와 검색 placeholder가 식별됩니다. |
| 장비 카드 | 3열 데스크톱 grid에서 카드의 이미지·제목·설명·메타·`자세히 보기`가 가독성 있게 표시되고 각 카드는 native detail link로 유지됩니다. |
| 버튼·포커스 계약 | 목록으로 돌아가기와 더보기 버튼은 CSS source test로 네이비 기본·골드 hover·focus outline·reduced-motion 규칙을 검증했습니다. 실제 CTA hover는 후속 검증에 기록합니다. |
| 데이터 상태 | 초기 로딩 표시는 정상 해제됐고 Best 시술 카드 6개가 표시됐습니다. |

전체 페이지 스크린샷 캡처는 같은 경로에서 1회 실패했습니다. 브라우저의 실제 렌더링 스크린샷과 DOM 접근성 요소 목록으로 대체 확인했으며, 실패 사실은 최종 보고에 유지합니다.

## 실제 스타일 확인

첫 장비 카드의 계산된 기본 스타일은 `background: rgb(238, 235, 228)` (`#EEEBE4`), `border-color: rgb(216, 208, 194)` (`#D8D0C2`), 기본 그림자 `rgba(26, 39, 68, 0.04) 0 2px 8px`, 상세 링크 금색 `rgb(122, 92, 53)` (`#7A5C35`)으로 확인됐습니다. 카드 위에 포인터를 둔 상태에서는 환경의 마우스 이동 결과가 기본 transform을 유지해, hover transition 값은 CSS source regression과 `(hover: hover)` 범위로 함께 검증합니다. 터치 환경에는 hover 상태가 고정되지 않도록 의도된 제한입니다.

# 장비 상세 모바일 밀도 검증 기록

## 적용 범위

공통 `Equipment3Detail` 템플릿을 쓰는 `/equipment3/:slug` 상세 경로에만 `max-width: 767px` 규칙을 추가했다. 데스크톱 규칙·URL·장비 콘텐츠는 변경하지 않았다.

## 대표 경로 점검

| 경로 | 확인 결과 |
| --- | --- |
| 울쎄라피 프라임 | 브라우저 원문에서 히어로, 소개, 시맨틱 원리, 기대 효과, 주의사항, FAQ, 영상이 정상 순서로 렌더되었고 새 피부 단면도 자산도 이미지로 제공되었다. |
| 써마지 | 자동 브라우저 도구가 사용 불가 상태로 전환되어 두 번째 경로의 원문 확인을 완료하지 못했다. 공통 템플릿 CSS의 범위 검증과 전체 회귀 테스트로 대체한다. |
| 엔라이튼 | 자동 스크린샷 도구가 동일 경로군에서 캡처에 실패해 시각 캡처 확인을 완료하지 못했다. 공통 템플릿 CSS의 범위 검증과 전체 회귀 테스트로 대체한다. |

## 공통 규칙

모바일에서만 본문 시작·섹션 간격을 압축하고, 카드 계열의 고정 높이를 해제해 내용 기반 높이를 유지한다. 긴 텍스트를 숨기거나 의료 문구를 변경하지 않는다. 데스크톱에는 `min-width` 규칙이나 기존 값을 변경하지 않았다.

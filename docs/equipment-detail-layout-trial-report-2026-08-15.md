# 시술·장비 상세 FAQ 우선 배치 시범 보고서

## 시범 범위

공통 `Equipment3Detail` 템플릿에서 저장형 FAQ와 리프팅 포지셔닝 FAQ를 **진료·시술 안내 고정 인용 블록보다 먼저** 배치했다. 이 템플릿은 72개 시술·장비 상세와 5개 언어 경로에 공통으로 사용된다. URL, 카테고리 탭, 메타데이터, MedicalProcedure·FAQPage 구조화 데이터, FAQ 문구, 예약·OTP 코드와 네이버·카카오 외부 예약 링크는 변경하지 않았다.

| 항목 | 기존 순서 | 시범 적용 순서 |
| --- | --- | --- |
| 본문 흐름 | 시술 소개 → 기대 효과 → 주의사항 → 진료·시술 안내 → FAQ | 시술 소개 → 기대 효과 → 주의사항 → FAQ → 진료·시술 안내 |
| FAQ 내용 | 변경 없음 | 변경 없음 |
| 고정 인용 블록 | 변경 없음 | FAQ 다음으로 위치만 이동 |
| URL·SEO 메타·구조화 데이터 | 변경 없음 | 변경 없음 |

## 검증 결과

타입 검사와 lint는 오류 없이 통과했고, 전체 Vitest는 **82개 파일·1,533개 테스트**를 통과했다. 메모리 정리 후 `NODE_OPTIONS=--max-old-space-size=3072 pnpm build`도 통과했다. 또한 최신 production 산출물에서 FAQ가 존재하는 72개 상세의 한국어·영어·일본어·중국어 간체·중국어 번체 **360개 원본 HTML 응답**을 검사해 `FAQPage` 및 전체 **1,395개 FAQ 질문**이 모두 포함되는 것을 확인했다.

운영 도메인의 중국어 번체 BBL 상세에서도 FAQ가 진료·시술 안내보다 먼저 나타나고, `BBL緊膚`, `釜山西面Star皮膚科` FAQ 안내, 고정 인용 블록이 정상 표시되는 것을 확인했다.

## 승인 요청

시범 변경은 공통 템플릿에 이미 적용되어 있으므로, 승인 시 현재 순서를 유지한다. 정보 구조를 기존 순서로 되돌리려면 공통 템플릿의 FAQ와 고정 인용 블록 위치만 이전하면 되며, 콘텐츠·URL·SEO 데이터에는 영향이 없다. **현 순서를 유지할지, 기존 순서로 되돌릴지** 사용자 확인이 필요하다.

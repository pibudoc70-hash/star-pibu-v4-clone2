# 장비 목록 모바일 밀도 및 다크 모드 검증 기록

## 사전 관찰

390×844 전체 페이지 캡처는 2026-08-29 개발 미리보기에서 1회 실패해 이미지 기준선은 생성되지 않았습니다. 같은 미리보기에서 브라우저 렌더링을 확인한 결과, `/equipment3`의 제목 아래에 아이콘과 함께 `다크 모드` 버튼이 표시되고, 장비 데이터 요청 중에는 기존 상태 안내 문구가 유지됐습니다. 데이터 로딩이 완료된 카드 목록의 실제 모바일 캡처는 후속 검증에서 별도 방식으로 확인합니다.

| 항목 | 사전 확인 결과 |
|---|---|
| 다크 모드 제어 | 제목·소개 아래에 독립 button으로 표시되며, 상태는 `aria-pressed`로 제공하도록 구현됨 |
| 로딩 접근성 | 기존 `role="status"`, `aria-live="polite"`, `aria-busy="true"` 구조를 유지 |
| 390px 캡처 | 전용 capture가 실패해 재시도하지 않고, 실제 브라우저·DOM 및 코드 기반 검증으로 보완 예정 |

## 실제 전환 확인

개발 미리보기의 `/equipment3`에서 장비 데이터가 로딩된 뒤 `다크 모드` button을 선택했습니다. 버튼 레이블과 접근성 이름이 `라이트 모드` 및 `라이트 모드로 전환`으로 바뀌었고, 페이지 바탕·카테고리 패널·검색·카드 본문이 다크 팔레트로 전환됐습니다. 카드의 실제 제목·설명·메타·상세 링크, 이미지, category tab, native detail link는 전환 후에도 유지됐습니다.

| 항목 | 실제 확인 결과 |
|---|---|
| 전환 상태 | 버튼의 표시명이 `다크 모드`에서 `라이트 모드`로, 접근성 이름이 `라이트 모드로 전환`으로 갱신됨 |
| 다크 표면 | 페이지 `#121A2D`, 카드 `#1C2943` 계열, 그룹 패널 `#172238` 계열의 명도 단계가 보임 |
| 읽기성 | 제목은 밝은 아이보리, 보조 텍스트는 청회색, 상세 링크와 active category는 골드로 표시되어 구분됨 |
| 기능 보존 | 검색 입력, 14개 category tab, Best 장비 카드, 이미지 및 native detail href가 유지됨 |

페이지를 다시 연 뒤에도 저장된 다크 모드 상태가 유지되어 제어 버튼은 `라이트 모드`로 표시됐습니다. 이 재진입 시점에는 장비 요청의 기존 로딩 상태가 잠시 표시됐고, 로딩 영역의 배경·아이콘·문구도 다크 표면에서 충분히 구분됐습니다.

계산된 스타일도 다크 토큰과 일치했습니다. page 배경은 `rgb(18, 26, 45)` (`#121A2D`), card 배경은 `rgb(28, 41, 67)` (`#1C2943`), card border는 `rgb(58, 75, 104)` (`#3A4B68`), 제목·검색 입력은 `rgb(246, 241, 232)` (`#F6F1E8`), 상세 링크는 `rgb(215, 181, 109)` (`#D7B56D`)으로 확인됐습니다. root에는 `equipment-list-page--dark`가 존재하고 toggle은 `aria-pressed="true"`, 저장값은 `equipment3_color_scheme=dark`였습니다.

동일 control을 다시 선택했을 때 라이트 모드로 복귀했습니다. root에서 `equipment-list-page--dark` class가 제거되고, `aria-pressed="false"`, 레이블 `다크 모드`, 저장값 `equipment3_color_scheme=light`가 함께 복원되는 것을 확인했습니다.

## 390px 카드 밀도 확인

전용 capture 서비스가 두 번 실패한 뒤, 개발 브라우저의 390×844px 기기 지표를 임시 에뮬레이션해 카드 구간을 캡처했습니다. 단일 열 카드에서 이미지가 184px(`11.5rem`)로 안정적으로 잘리고, 제목은 약 15px·본문은 13px·메타는 12px로 계층이 유지됩니다. 14px 본문 padding, 약 16px 카드 간격, 44px 이상 상세 링크 터치 영역이 겹침 없이 표시됐습니다. 첫 카드의 제목·두 줄 소개·시술 시간/회복 메타·상세 링크와 다음 카드의 상단 이미지가 한 화면 안에 자연스럽게 이어져, 이전 200px 이미지와 380px 최소 높이에서 발생하던 불필요한 세로 점유를 줄였습니다.

| 조정 | 390px 확인 결과 |
|---|---|
| 카드 이미지 | `200px`에서 `11.5rem`(184px)으로 축소해 첫 카드가 과도하게 길어지지 않음 |
| 본문 여백 | `16px`에서 `14px`로 조정해 정보 밀도를 높이되 제목·메타·CTA의 구획을 유지 |
| 글꼴 및 줄 간격 | 제목 15px/1.45, 소개 13px/1.55, 메타 12px/1.45로 작은 화면에서도 읽기 쉬운 line-height 유지 |
| 터치·키보드 | 상세 링크와 category tab의 최소 높이를 44px로 보존해 조밀해져도 조작 대상이 작아지지 않음 |

같은 390×844px 카드 구간을 다크 모드로도 캡처했습니다. 네이비 배경 위의 카드 표면, 아이보리 제목, 청회색 보조 텍스트, 골드 `자세히 보기`가 이미지와 분명히 분리됐습니다. 이미지 비율과 single-column 정보 흐름은 라이트 모드와 동일하게 유지되어, 모드 전환이 카드 수·순서·상세 링크 경로·검색·카테고리 동작을 바꾸지 않음을 시각적으로도 확인했습니다.

상단 헤더도 dark surface로 함께 전환하도록 보완한 뒤 다시 확인했습니다. 390px 캡처에서 로고·햄버거 버튼·검색 상단·카드 영역이 끊김 없이 네이비 계열로 연결되고, 햄버거의 gold outline과 카드의 gold detail link가 명확한 조작·행동 단서로 보였습니다.

## 다크 모드 팔레트 및 WCAG 대비

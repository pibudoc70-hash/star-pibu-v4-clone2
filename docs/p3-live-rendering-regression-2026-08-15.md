## 추가 진단

대표 도메인의 CSS asset(`/assets/index-mk3czdg1.css`)은 HTTP 200, `text/css`, 260,744 bytes로 응답했다. 브라우저에서도 524개의 CSS 규칙이 로드됐고 body font가 `Noto Sans KR`로 계산됐다. 따라서 첫 브라우저 캡처의 평문 표시는 CDN의 CSS 제공 실패가 아니라 해당 브라우저 캡처 상태 또는 특정 렌더링 타이밍과 관련된 현상으로 재분류한다. 대표 도메인과 별도로 프로젝트 도메인의 timeout은 계속 진단 대상이다.

대표 도메인 재방문에서는 히어로 배경, 고정 헤더, 메뉴, 카카오 상담·네이버 예약 CTA, 의료진 탭, FAQ, 위치·푸터가 스타일과 함께 정상 렌더링됐다. 프로젝트 도메인의 두 차례 curl timeout은 플랫폼 라우팅 상태로 분리 기록하며, 대표 운영 도메인의 실제 공개 기능에는 재현되지 않았다.

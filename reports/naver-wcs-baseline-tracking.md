# 네이버 WCS 공통 추적 적용 기록

## 적용 범위

제공된 WCS 계정 `s_248ada83bcd2`를 사용해 **`star-pibu.com` 및 `www.star-pibu.com`에만** 네이버 WCS 공통 스크립트를 추가했다. 공개 `.co.kr`, Manus 미리보기, 로컬 개발 호스트에는 태그를 초기화하지 않는다. 공통 태그는 유입 및 네이버 광고 전환 귀속의 기반을 마련하며, 별도의 완료 전환 스크립트나 예약·상담 이벤트는 이번 변경에 포함하지 않았다.

| 항목 | 적용 상태 | 경계 |
|---|---|---|
| WCS 공통 스크립트 | 적용 | `https://wcs.naver.net/wcslog.js` 1회 삽입 |
| 계정 설정 | 적용 | `wcs_add.wa`에 제공된 계정만 설정 |
| 유입·공통 호출 | 적용 | 스크립트 로드 후 `wcs.inflow()` 및 `wcs_do()` 호출 |
| 예약·상담·폼 값 | 미전송 | 전화번호, 성명, 시술 관심사, URL query/hash를 전달하지 않음 |
| Google Ads 전환 | 보류 | `AW-...` 및 전환 라벨 미제공 |

## 보안 및 고지

Content Security Policy에는 WCS 스크립트, 이미지형 수집, 연결 요청에 필요한 `wcs.naver.net`만 추가했다. 개인정보처리방침의 위탁 목록에는 네이버 WCS의 웹사이트 유입 및 광고 전환 통계 분석 목적을 추가했다. 실제 법적 고지의 적합성은 운영 주체의 최종 검토가 필요하다.

## 검증

WCS 계정 문맥으로 공식 스크립트 응답을 확인했으며, helper 단위 테스트에서 유효 계정 형식, `.com` 한정 초기화, 단일 script 삽입, script load 이후 inflow·공통 호출을 검증했다. CSP 및 개인정보 고지 회귀 테스트와 전체 품질 게이트도 실행했다. 자동 배포 뒤에는 `star-pibu.com`의 실제 WCS 요청을 추가 확인한다.

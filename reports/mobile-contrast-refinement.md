# 모바일 대비 정돈형 적용 기록

## 범위

승인된 A안은 767px 이하 화면에만 적용했다. 페이지의 웜 화이트 캔버스는 `#FAF8F5`로 유지하고, 교차 표면은 `#F5F0EB`, 카드 표면은 `#FFFDF9`로 정돈했다. 제목의 진한 차콜은 유지하되, 보조 본문은 `#4F4B47`, 캡션은 `#625B54`로 통일했다. 데스크톱 색상 토큰, 문구, 레이아웃, 예약·OTP·외부 예약 흐름은 변경하지 않았다.

## 시각 검토와 보정

390px Chromium 캡처에서 홈의 네이비 hero·CTA는 기존 흰색 글자 대비가 충분해 그대로 보존했다. 장비 목록에서는 오프화이트 카드 표면과 진한 제목의 계층이 안정적으로 보였다. 다만 골드 활성 카테고리의 작은 흰색 label은 대비가 약해 보였으므로, 모바일에서만 네이비 글자·아이콘으로 보정했다. 골드는 활성 표면·테두리·포커스 포인트로 유지한다.

| 검증 항목 | 결과 |
|---|---|
| 모바일 적용 폭 | 390×844px 시각 확인 |
| 캔버스·교차 표면 | `#FAF8F5` · `#F5F0EB` 유지 |
| 카드 표면 | `#FFFDF9` |
| 보조 본문·캡션 | `#4F4B47` · `#625B54` |

# 모바일 SPECIAL EVENT 클릭 동작 검증

## 동작 분리

모바일 이벤트 행은 저장된 연결 URL 유무와 무관하게 `button`으로 렌더된다. 따라서 이벤트명·가격이 보이는 접힌 행과 우측 원형 화살표는 같은 아코디언 토글을 실행한다. 저장된 `http` 또는 `https` 연결 URL은 펼친 `EventInlineDetail` 내부의 썸네일에만 새 탭 링크로 적용되며, 이미지 링크는 `stopPropagation()`으로 행 토글과 분리된다.

연결 URL이 없는 이벤트는 기존과 같이 행을 눌러 상세를 열고, 상세 썸네일에는 링크가 생성되지 않는다. 데스크톱 `EventCard`는 수정하지 않아 기존 카드 전체의 안전한 새 탭 연결 동작을 그대로 유지한다.

## 검증

TypeScript 검사와 모바일 행·상세 이미지 링크·데스크톱 카드·서버 URL 검증 집중 테스트 15개가 통과했다. 테스트는 연결 URL이 있는 행도 먼저 `aria-expanded` 아코디언 버튼임을 확인하고, 펼친 상세 내부에만 `target="_blank"` 및 `rel="noopener noreferrer"` 링크가 있음을 검증한다.

2026-09-17에 390×844 모바일 및 1280×720 데스크톱의 전체 페이지 화면 캡처를 시도했으나, 캡처 런타임 오류로 이미지가 생성되지 않았다. 이 때문에 시각적 결과를 주장하지 않으며, 상호작용 회귀 테스트와 데스크톱 소스 불변으로 검증 근거를 남긴다.

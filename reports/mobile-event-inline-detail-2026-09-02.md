# 모바일 스페셜 이벤트: 카드별 인라인 상세 전개

## 적용 범위

모바일 `EventTableMobile`의 각 이벤트 행을 하나의 native button으로 전환했다. 사용자는 제목·가격·VAT 배지를 포함한 행 어디를 누르더라도 해당 행 바로 아래에서만 상세를 열 수 있으며, 다른 이벤트를 누르면 기존 상세는 닫히고 새 선택 항목만 열린다.

목록 상단에는 **“원하는 이벤트를 누르면 상세 내용과 가격을 확인할 수 있어요.”** 안내를 표시했다. 이 안내와 `상세 보기`·`상세 접기`는 ko/en/ja/zh/zh-TW별로 제공한다. 상세의 하단 닫기 동작은 기존처럼 선택 행으로 부드럽게 복귀한다.

## 보존한 계약

데스크톱 EventCard 레이아웃, 이벤트 제목·가격·VAT 표기, 카카오/LINE/WeChat 상담 링크, 전화 링크, 예약·OTP·외부 예약 흐름은 바꾸지 않았다. 행은 `aria-expanded`와 `aria-controls`를 갖고, 키보드 포커스 링을 제공한다.

## 검증

`EventTableMobile.test.tsx`와 `EventTableMobile.verticalList.test.ts`는 총 8개 테스트를 통과했다. 전체 `pnpm check`, `pnpm lint`, `pnpm test:unit`, `pnpm build`도 통과했다.

390px CDP 터치 측정은 지연 마운트된 이벤트 목록이 해당 자동화 세션에서 대상 탐색 시간 안에 나타나지 않아 DOM 터치를 완료하지 못했다. 단위 테스트는 전체 행 클릭·선택 항목 전개·기존 상세 접기·단일 항목 확장·안내 표시를 직접 검증한다. 실제 개발 미리보기에서의 최종 탭 확인은 다음 운영 QA 시 재확인한다.

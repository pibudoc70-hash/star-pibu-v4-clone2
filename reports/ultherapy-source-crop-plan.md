# 울쎄라피 원본 인포그래픽 일러스트 크롭 계획

원본 `ultherapy_infographic_ko_bc4f4f15.webp`는 1440×1800px입니다. 새 시맨틱 섹션에는 원본 전체를 반복하지 않고, CSS 배경 위치를 이용해 텍스트 영역을 피한 아래의 장식용 일러스트 영역만 노출합니다.

| 적용 위치 | 원본에서 피할 요소 | 표시할 일러스트 영역 |
| --- | --- | --- |
| 피부층과 목표 깊이 | 상단 제목·좌우 레이어 라벨·우측 깊이 숫자 | 초음파 기기, 피부 단면, 세 개의 빛나는 타깃 포인트 |
| 4단계 카드 | 카드 상단의 원본 한글 제목·설명 | 초음파 화면, 깊이 타깃, 열응고점, 콜라겐 구조 그래픽 |
| 회복 과정 | 원본 타임라인의 한글 라벨·설명·화살표 | 느슨한·재정렬 중·정돈된 콜라겐 원형 그래픽 |

모든 의학적 문구는 이미 추가된 실제 HTML 텍스트를 유지하며, 크롭 이미지는 `aria-hidden` 장식으로만 사용합니다.

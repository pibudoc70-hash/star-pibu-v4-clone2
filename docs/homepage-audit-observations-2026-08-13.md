## 오시는 길 페이지

- 대상 URL: `https://star-pibu.com/directions`
- 주소·전화·진료시간·카카오맵·네이버지도 외부 링크는 렌더링되었으나, 데스크톱 지도 영역은 실제 지도 타일·임베드 대신 큰 회색 빈 영역으로 나타났다.
- 같은 페이지에서 본문은 `서면역 5·7번 출구 도보 3분`, Footer는 `도보 2분`으로 표기되어 있어 위치 안내 정보의 단일 원본 관리가 필요하다.
- 활성 `/directions` 라우트는 `client/src/pages/Directions.tsx`를 사용하지만, 파일 상단 주석은 이를 비활성·고아 페이지로 기술해 실제 코드와 문서가 불일치한다.
- 현재 iframe 원본 URL(`https://maps.google.com/maps?...&output=embed`)은 외부 응답 확인에서 HTTP 404를 반환했다. CSP에는 Google Maps 프레임 출처가 허용돼 있으므로, 우선 원인은 CSP가 아니라 iframe URL·공급자 동작의 신뢰성으로 판단한다.
- `/zh-tw/directions`에서도 같은 회색 빈 지도 영역이 재현됐다. 따라서 지도 문제는 한국어 단일 페이지가 아니라 공통 `Directions` 컴포넌트의 다국어 영향 문제다.
- 번체 중국어의 주소 복사(`複製地址`)·Google Maps 길찾기·Footer 주요 라벨은 현지화되어 렌더링되었다. 다만 동일 페이지 본문 교통 안내는 `도보 3분`, Footer는 `도보 2분`으로 언어와 무관하게 불일치한다.

# 외부 예약 링크 및 안정성 읽기 전용 감사 보고서

**작성일:** 2026-08-14  
**범위:** 사용자 선택 1에 따라 예약·OTP 코드, DB, API, 내부 관리자 예약 기능을 수정·삭제·비활성화하지 않고, 공개 네이버·카카오 진입점과 링크 안전성만 읽기 전용으로 점검했다.

## 1. 작업 요약

현재 공개 홈과 대표 장비 상세는 네이버 예약 및 카카오톡 상담으로 사용자를 유도하며, 확인한 외부 링크에는 새 창 보안 속성이 적용되어 있다. 반면 소스 인벤토리에서는 내부 예약 섹션으로 이동하는 경로와 내부 예약·OTP 모듈이 여전히 유지되고, 네이버 예약 비즈니스 ID가 두 개로 분산되어 있음을 확인했다. 이번 단계에서는 확정된 비변경 제한을 지키기 위해 어느 기능도 변경하지 않았으며, 정책 완전 일치를 위한 수정 권고만 제시한다.

> **감사 판정:** 공개 핵심 CTA의 외부 링크 보안은 적합하나, "네이버·카카오만 사용" 정책의 완전한 충족 여부는 **조건부**다. 내부 예약 경로와 복수 외부 예약 URL이 공존하므로, 향후 정책 변경 승인이 있을 때 별도 구현 단계가 필요하다.

|---|---|---|---|
| 홈 헤더·Hero | 카카오톡 상담과 네이버 예약 CTA 노출 | 카카오 `/_HNyGC`, 네이버 `bizes/209080`; `target="_blank"`, `rel="noopener noreferrer"` 확인 | 적합 |
| 울쎄라피 프라임 상세 | 상단·본문 CTA가 카카오와 네이버로 이동 | 홈과 같은 URL·보안 속성 확인, 내부 예약 폼 미노출 | 적합 |
| 외국어 안내 상단 | 카카오톡·네이버 예약 CTA 노출 | 카카오 `/_HNyGC`, 네이버 `bizes/209080`; 새 창·보안 속성 확인 | 적합 |

## 3. 코드 구성과 발견 사항

외부 예약 URL의 기준값은 `client/src/lib/constants.ts`에서 네이버 `bizes/209080`, 카카오 `/_HNyGC`로 정의되어 있다. 그러나 `client/src/hooks/useChatConfig.ts`는 동일한 네이버 URL 외에 `naverAlt`(`bizes/1122956`) 및 이전 카카오 URL을 보유하며, `TreatmentDetail.tsx`와 `ForeignGuide.tsx`에서는 `bizes/1122956`를 직접 사용한다. 따라서 외부 예약 URL은 아직 완전한 단일 원본으로 관리되지 않는다.

또한 `client/src/lib/reservationPath.ts`는 언어별 홈의 `#reservation` 내부 경로를 반환하고, `TreatmentPage.tsx`, `Equipment2Detail.tsx`, `MyPage.tsx`, `MyReservations.tsx`에서 이를 사용한다. 외국어 환경의 `useChatConfig`는 중국어에 WeChat/LINE, 일본어에 LINE/OTOMO Busan을 상담·예약 보조 채널로 선택한다. 이는 다국어 지원 맥락에서는 의도된 동선일 수 있으나, "고객 예약은 네이버·카카오만"이라는 새 정책을 엄격히 적용할 경우 검토가 필요하다.

## 5. 비변경 확인

이번 감사에서 예약 라우터, OTP 모듈, 예약 DB 테이블, 예약 이메일·SMS, 관리자 예약 기능, 예약 관련 테스트는 수정하지 않았다. 운영 DB 데이터와 네이버·카카오 외부 예약 데이터도 생성·수정·삭제하지 않았다. 감사 산출물과 작업 목록 기록만 추가했다.

## 6. 남은 위험 및 정책 변경 시 권고

정책 변경 승인이 있을 경우에는 먼저 `bizes/209080`과 `bizes/1122956` 중 실제 사용해야 할 네이버 예약 목적지를 운영자가 확정해야 한다. 확정 후에는 공통 상수 한 곳으로 URL을 통합하고, 직접 하드코딩된 호출을 그 상수로 교체하는 방식이 가장 안전하다.

그 다음 단계에서만 내부 예약 경로·폼·사용자 예약 내역 화면·공개 API의 사용자 노출 여부를 의존성 단위로 검토해야 한다. 그러나 내부 예약·OTP 모듈은 관리자·인증·기존 테스트와 연결되어 있으므로, 삭제나 비활성화가 아닌 사용자 공개 진입점만 외부 링크로 전환하는 방식을 먼저 검토하는 것이 안전하다. 현재 확정 제한에서는 이 구현을 수행하지 않았다.

## 7. 최종 판정

**읽기 전용 감사 완료.** 대표 공개 CTA의 외부 링크 보안과 기본 서버 응답은 정상이다. 다만 내부 예약 경로와 복수 네이버 URL이 남아 있으므로, 네이버·카카오 전용 정책의 완전한 구현은 아직 완료 상태로 판정할 수 없다. 해당 변경은 별도의 명시적 정책 변경 승인 후에만 진행해야 한다.

# 스타피부과 백링크 전략: 90일 실행안

> **한계 고지:** 이 문서는 Ahrefs·Semrush·DataForSEO 또는 Search Console의 원시 링크 데이터를 사용한 백링크 프로필 감사가 아닙니다. 따라서 현재 referring domain 수, 도메인 권위, 독성 링크 비율, 경쟁사 gap을 추정하거나 단정하지 않습니다. 아래 제안은 공개적으로 확인한 지역 인용 상태와 Google·의료광고 기관의 공식 가이드에 근거한 **실행 전략**입니다.

> **의료광고 유의:** 저는 변호사가 아닙니다. 아래 내용은 실무 전략이지 법률 자문이 아니므로, 유료 기사·제휴 콘텐츠·외부 플랫폼의 의료 홍보 문구는 게시 전 의료광고 심의 기준과 담당 법률/심의 전문가의 검토를 받으십시오.

## 핵심 판단

스타피부과의 링크 전략은 “울쎄라·써마지 키워드를 많이 넣은 링크를 대량 구매”하는 방식이 아니라, **부산 서면의 실재 의료기관이라는 신뢰 신호를 일관되게 정리하고, 검증 가능한 의료진·연구·환자 안내 자료가 필요한 문맥에서 자연스럽게 인용되도록 만드는 방식**이 적합합니다. Google은 순위 조작을 위한 링크 구매·판매, 과도한 상호 링크, 자동 링크 생성, 저품질 디렉터리 및 사이트 전체 footer/template 링크를 link spam으로 명시합니다.[1]

공개 표본에서는 굿닥의 스타피부과 인용이 주소·전화·의료진 3명을 표시하지만 공식 웹사이트 연결 정보는 없다고 표기합니다.[2] 모두닥에는 “홈페이지” 동작이 보이지만 해당 목적지는 이번 표본 점검에서 별도로 검증하지 않았습니다.[3] 이 두 항목은 새 링크를 사는 일보다 먼저 처리할 **고신뢰 인용 정비 기회**입니다. Google은 Business Profile의 완전하고 정확한 업체 정보, 웹사이트 링크·리뷰 등 웹 전반의 신호가 지역 관련성·인지도에 영향을 준다고 설명합니다.[4]

|---|---|---|---|---|
| P0 | 공식 entity citation | Google Business Profile, 네이버 스마트플레이스, 카카오맵/카카오톡채널, 굿닥, 모두닥 | `/`, `/directions`, `/doctors` | 상호·대표 전화·도로명 주소·진료시간·공식 도메인 `https://star-pibu.com`을 모든 채널에서 하나의 정본으로 일치 |
| P1 | 의료진·연구의 evidence link | 학회 발표 페이지, 대학·병원 교육 프로그램, 논문 DOI/학술 검색 서비스, 공식 강연/세미나 페이지 | `/doctors`, `/research` | 실제 참여·논문·발표만. 소개 페이지나 프로필을 새로 만들기 전 원문·주최자·날짜를 확인 |
| P1 | 환자 안내형 earned link | 부산 지역 공공·건강 정보 기관, 검증된 건강 매체의 환자 안내/인터뷰, 비영리 공중보건 캠페인 | 해당 주제의 `/treatments/:slug`, `/research`, `/directions` | 교육·안전·내원 안내 문맥만. 결과 보장·할인 유인·전후 사진 중심 advertorial은 제외 |
| P2 | 공식 동영상/사회 채널 entity support | YouTube 공식 채널, Instagram, 네이버 블로그, 카카오채널 | `/`, 개별 시술 안내 URL | 영상 설명란·프로필에서 homepage 또는 주제별 안내 페이지로 연결하되 반복 키워드 anchor를 강요하지 않음 |
| P2 | 지역 커뮤니티 신뢰 신호 | 부산진구·서면 상권/커뮤니티의 실제 협력·공익 활동 기록 | `/directions` 또는 실제 활동 페이지 | 단순 광고 패키지보다 실제 협력의 지속성·사실 확인·심의 가능성을 우선 |

## 90일 실행 순서

| 기간 | 해야 할 일 | 완료 기준 | 피해야 할 일 |
|---|---|---|---|
| 1–2주 | **정본 확정:** 상호, 의료기관명, 대표 전화, 도로명 주소, 층별 안내, 진료시간, `https://star-pibu.com`를 1장짜리 entity sheet로 확정. Google·네이버·카카오·굿닥·모두닥의 소유권/수정 요청 경로를 점검 | 5개 핵심 채널의 정보 표와 각 수정 요청 상태 | 채널마다 다른 URL·전화·주소 사용, 오래된 `star-pibu.co.kr`를 공식 도메인으로 혼용 |
| 3–4주 | **P0 citation 정비:** 굿닥에 공식 사이트 연결 추가를 요청하고, 모두닥 홈페이지 목적지·모바일 동작을 확인. 네이버 스마트플레이스·Google Business Profile·카카오맵의 NAP와 카테고리를 정본과 대조 | 최소 3개 핵심 인용에서 동일한 공식 domain 및 NAP 확인 | 로그인 대행/무단 계정 생성, 허위 사진·가짜 리뷰·보상성 리뷰 요청 |
| 5–6주 | **링크 받을 자료 준비:** 의료진 연구/발표 proof table, 시술 전후 안전 안내, 오시는 길·대중교통, 기존 YouTube의 근거 기반 설명을 정리. 각 자료는 소유자·날짜·출처·검수 상태를 보유 | outreach에 쓸 3개 자료와 정확한 deep link 확정 | 기존 의료 문구를 근거 없이 늘리거나 효과·개인차를 단정하는 링크용 콘텐츠 작성 |
| 7–9주 | **선별 outreach:** 실제 발표 주최자, 논문/학회 관계자, 지역 건강 정보 편집자, 공익 활동 파트너에 factual correction 또는 reference 요청 | 매주 5–10개 고관련성 대상에 개별화된 요청. 게재 여부·nofollow/sponsored 여부를 기록 | 대량 이메일, “부산울쎄라 1위” 같은 exact-match anchor 요청, 링크 교환 약속 |
| 10–12주 | **품질 검토:** 새 링크·인용을 URL, source type, target page, date, attribute, approval evidence로 ledger화. 끊긴 링크·틀린 NAP 수정 | 실제 신규 고품질 referring domain, P0 NAP 일치율, deep page referral 기록 | raw backlink 수를 성과로 포장하거나, 출처 미상의 링크를 독성/정상으로 단정 |

## 링크 대상과 anchor 운영 원칙

일반적으로 링크의 대부분은 **브랜드명, 의사명, URL, 자연스러운 문장**이어야 합니다. 외부 운영자에게 “부산울쎄라”, “서면피부과” 같은 정확일치 anchor를 반복 요구하지 마십시오. Google은 최적화된 anchor를 포함하는 유료 advertorial·guest post·press release도 ranking credit을 전달할 때 정책 위반 사례로 제시합니다.[1]

| 외부 문맥 | 우선 target | 자연스러운 anchor 예시 | 이유 |
|---|---|---|---|
| 병원 목록·지도 | `/directions` 또는 `/` | 스타피부과의원, 공식 홈페이지, 부산진구 서면로 74 | entity·위치 확인에 적합 |
| 의료진 이력·학회·발표 | `/doctors`, `/research` | 조시형 원장 프로필, 의료진 소개, 발표/연구 자료 | 실제 경력·출처와 deep link를 일치 |
| 시술의 일반 안전 안내 | 해당 `/treatments/:slug` | 시술 안내, 상담 전 확인사항, 관련 안내 페이지 | 진단·효과 보장이 아닌 정보 제공 맥락 |
| 공식 동영상 | `/` 또는 해당 상세 안내 | 스타피부과 YouTube, 영상에서 언급한 안내 | 비디오와 웹 정보의 entity 연결 |

| footer/sitewide 파트너 링크 | 비자연적 반복·문맥 없는 링크가 될 수 있음 | 실제 협력 활동 페이지 한 곳에서 사실 기반으로 제한 |
| PBN·만료 도메인·링크 패키지 | 출처·편집 기준·유지 보수 불명, 수동 조치·평판 위험 | 출처별 영업/학회/편집 근거가 남는 링크만 ledger에 기록 |
| 타 병원·의료진을 공격하는 비교형 콘텐츠 | 의료광고·명예·사실성 위험 | 중립적인 시술 선택·안전 안내와 출처 있는 전문성 자료 |

## 측정과 의사결정

첫 90일은 raw backlink 숫자보다 **검증된 referring domain과 entity 일치**를 핵심 KPI로 둡니다. 매월 첫 영업일에 아래 ledger를 갱신하고, 출처가 불명확한 링크는 단순 검토 대상으로 남깁니다. 신뢰도·독성 판정이나 disavow는 실제 link export 없이 진행하지 않습니다.

| KPI | 측정 방법 | 90일의 합리적 목표 |
|---|---|---|
| P0 NAP 일치 | 5개 핵심 채널의 상호·전화·주소·URL 수동 대조 | 5/5 정본 일치 |
| 공식 도메인 연결 | 핵심 인용의 website field/mobile target 확인 | 굿닥 포함 누락 채널을 우선 해소 |
| 신규 품질 referring domain | 실제로 확인한 고관련성·편집형 또는 공식 기관 도메인 | 양보다 출처·문맥·유지 가능성을 기록 |
| deep-page 비중 | `/doctors`·`/research`·실제 시술 안내 URL을 향한 새 링크 비율 | 홈페이지 편중을 줄이되 인위적 배분은 하지 않음 |
| 브랜드 검색·프로필 행동 | Search Console/Business Profile/스마트플레이스의 공개 가능한 추세 | 링크 수가 아니라 discoverability 보조 지표로 해석 |
| 오류 정정 완료율 | 잘못된 URL·NAP·의사 표기 수정 요청의 처리 상태 | 요청·승인·반영 일자를 ledger에 기록 |

## 데이터 기반 감사로 전환하는 조건

현재 전략은 데이터 제한 상태입니다. 90일 뒤 실제 프로필 건강도·독성 링크·anchor 분포·유실 링크·경쟁 gap을 분석하려면 아래 중 하나가 필요합니다. 이 데이터가 준비되면 별도 승인 후 **백링크 감사**를 수행하며, 그 전에 현재 수치나 독성 링크를 추정하지 않습니다.

| 우선순위 | 필요한 데이터 | 확보 방법 |
|---|---|---|
| 1 | Ahrefs/Semrush/DataForSEO의 referring domains, live/lost backlinks, anchors, best pages 90일 export | MCP 또는 API 연결 |
| 2 | Google Search Console Links report export와 Performance의 branded/non-branded 추세 | CSV/XLSX 업로드 |
| 3 | Naver Search Advisor·스마트플레이스의 유입/업체정보 점검 export | CSV/XLSX 업로드 또는 화면 캡처 |
| 4 | 비교할 부산 피부과 2곳의 도메인 | 경쟁사 backlink comparison은 추가 referring-domain 데이터가 필요함 |
